Trajectory Analysis & Physics-Informed Neural Network (PINN)

Analytical acceleration regularized trajectory estimation (pinn_trajectory.m).

GATE A PENDING
PINN Trajectory Model Formulation:
z(t) = line(t) + σ · NN((t - t0) / Ts)
Loss = mean((NN - res)/σ)² + λ_acc · mean((d²z/dt² / accScale)²) + λ_w · ||θ||²
The constant-velocity line serves as the zero-acceleration baseline. The small tanh neural network bends the path to fit detections while penalizing non-physical accelerations at collocation points across the query horizon.
Architecture
8 Tanh Units
Single hidden layer backprop
Training Horizon
3,000 Epochs
Adam optimizer (lr=0.01)
Physics Weight (λ)
1.0
accScale = 0.5 px/frame²
Ensemble Members
5 Networks
Spread = empirical uncertainty
